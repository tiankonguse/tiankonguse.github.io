## 一、找出两个字符串的不匹配片段


题意：给两个长度相同的字符串，求所有的下标区间，使得两个字符串对应区间内相同下标的字符都不相同。  


思路：双指针  


左指针是首次不同的位置，右指针遇到相同的位置，找到一个答案。  
复杂度：`O(n)`  


## 二、统计有效后缀排序的数量 I


题意：给两个长度相等的数组，问第一个数组有哪些下标，将下标开始的后缀非递增排序后，使得两个数组相等。  


思路：枚举  


首先需要两个数组字符集合与个数完全一致，最终才会一致，先进行特判。  


其次，如果一个下标满足要求，则这个下标之前的两个数组的前缀，肯定是相等的。  
而下标的后缀，第二个数组需要满足非递增性质。  


![](https://res2026.tiankonguse.com/images/2026/11/24/001.png)


对于前缀，可以预处理最长的相等位置。  
对于后缀，也可以预处理最长的非递增位置。  


对于每个下标，判断前缀是否都相等，后缀是否都非递增即可。  
复杂度：`O(n)`  


## 三、使红色节点连通的最小代价


题意：给一个有根树，每个节点的颜色为红色或者蓝色。  
现在可以把某些节点颜色反转，代价是节点为根子树的大小。  
问最小代价，使得所有红色节点是连通的。  


思路：换根DP  


思路很简单，枚举节点为红色的根，计算答案。  


如下图，假设紫色箭头指向的点作为根。  
则，需要把这个子树之外的所有红色节点都变成蓝色。  


![](https://res2026.tiankonguse.com/images/2026/11/24/002.png)


这就预处理每个节点作为根的子树大小 `S(x)`，以及每个节点子树红色都转化蓝色的代价`T(x)`。  
然后，子树之外红色转化蓝色的代价就是 `T(0) - T(B)`。  


对于子树根 B 的儿子，有两种选择：要么把儿子子树都转变为蓝色，要么儿子也是红色，需要看谁更优。  


![](https://res2026.tiankonguse.com/images/2026/11/24/003.png)


复杂度：`O(n)`  
注：这个算是最简单的换根DP，不需要考虑父路径的状态，不需要考虑儿子之间的关系。  


```cpp
// 子树外都是蓝色的代价
void DfsBlueRed(int u, int pre) {
  rootRedCost[u] = allBlueCost[0] - allBlueCost[u];
  if (colors[u] == 'B') {
    rootRedCost[u] += childCnt[u];
  }
  for (int v : g[u]) {
    if (v == pre) {
      continue;
    }
    DfsBlueRed(v, u);
    // 子树可以选择全部蓝色，也可以选择子树根是红色，取最小代价
    rootRedCost[u] += min(allBlueCost[v], rootRedCost[v]);
  }
  ans = min(ans, rootRedCost[u]);
}
```


## 四、统计有效后缀排序的数量 II


题意：给两个数组 nums 和 target，其中 target 数组更长一些。  
问对于所有 target 的所有与 nums 长度相同的子数组中，有多少个下标 i，满足 nums 对下标 i 后缀非递增排序后，使得 nums 与子数组相等。  


思路：字符串hash 或 后缀数组  


首先是滑动窗口维护大小为 nums 的窗口，先判断两个集合的元素是否完全相等，相等了排序才可能相等。  


之后，就与第二题一样，需要判断前缀是否都相等，以及后缀是否都非递增。  


对于非递增，可以提前预处理好，之后`O(1)`使用。  


对于前缀是否都相等，比较麻烦。  


如果把 `nums` 与 `target` 拼在一起，则是标准的后缀数组问题，只需要求 `LCS(0, i)` 即可求出相等的前缀长度。  


当然，对于 `LCS`，Z函数也可以解决。  
复杂度：`O(n+m)`  


如果不想使用字符串匹配，终极方法是二分+字符串 hash。  
前缀相等时，字符串hash也相等。  
因此可以二分找到边界，从而计算出相等前缀的长度。  
复杂度：`O(n log(n))`
